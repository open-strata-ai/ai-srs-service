## 1. API Contract

### 1.1 Transport & Conventions

| Aspect | Specification |
| --- | --- |
| Protocol | REST (Spring MVC + SpringDoc OpenAPI 3) |
| Base Prefix | `/api/v1` |
| Internal gRPC | `SrsResolver` for Agent engine (proto in `specs/`) |
| Auth Header | `Authorization: Bearer <JWT>` + `X-Tenant-Id` |
| OpenAPI | `openapi.yaml` auto-generated by SpringDoc |

### 1.2 API Endpoint Table

| Method | Path | Description | Auth Role |
| --- | --- | --- | --- |
| `POST` | `/skills` | Register Skill | developer |
| `POST` | `/skills/{name}/versions` | Publish new version | developer |
| `GET` | `/skills/{name}` | Get current version | developer+ |
| `GET` | `/skills/{name}/versions/{ver}` | Get specific version | developer+ |
| `POST` | `/skills/{name}:deprecate` | Deprecate Skill | admin |
| `POST` | `/skills:resolve-deps` | Resolve DAG dependencies | developer |
| `GET` | `/rules` | List Rules | developer+ |
| `POST` | `/rules` | Define Rule | developer |
| `POST` | `/rules/{id}:dry-run` | Dry-run Rule | developer |
| `PATCH` | `/rules/{id}` | Enable/disable Rule | admin |
| `POST` | `/specs` | Create Spec | developer |
| `POST` | `/specs/{id}:validate` | Runtime validation | Agent engine |
| `GET` | `/resolve?kind=&name=&ver=&tenant=` | Runtime retrieval/load | Agent engine |
| `POST` | `/skills/{name}/versions/{ver}:test` | Run Skill test (Promptfoo) | developer |

### 1.3 HTTP Status Codes

| Code | Meaning |
| --- | --- |
| `2xx` | Success |
| `400` | Schema invalid |
| `401` | Unauthenticated |
| `403` | Unauthorized |
| `404` | SRS not found |
| `409` | Version already exists / dependency conflict |
| `422` | Dependency graph contains cycle or exceeds version range |
| `500` | Internal server error |

### 1.4 Error Response Schema

```json
{
  "code": "SKILL_DEP_CYCLE",
  "message": "Skill dependency contains cycle: auth_check → query_order → auth_check",
  "traceId": "c0ffee",
  "doc": "https://docs.openstrata.cc/errors/SKILL_DEP_CYCLE"
}
```

### 1.5 Business Error Codes

| Code | HTTP | Description |
| --- | --- | --- |
| `SKILL_DEP_CYCLE` | 422 | Dependency graph contains cycle |
| `SKILL_DEP_VERSION` | 422 | No version satisfies declared range |
| `SKILL_NOT_FOUND` | 404 | Skill does not exist |
| `RULE_NOT_FOUND` | 404 | Rule does not exist |
| `SPEC_NOT_FOUND` | 404 | Spec does not exist |
| `VERSION_CONFLICT` | 409 | Version already exists |
| `SPEC_VALIDATION_FAILED` | 400 | Input/output failed JSON Schema validation |
| `RULE_ENGINE_UNSUPPORTED` | 400 | Requested rule engine not configured |

## 2. Data Model

### 2.1 Database

| Attribute | Value |
| --- | --- |
| Engine | PostgreSQL 16.0 (core, §16 base) |
| Schema | `srs` (shared) |
| Multi-tenant isolation | `tenant_id` column + RLS (§8.2) |
| ORM | JPA (Hibernate 6 / Jakarta Persistence) |
| Migration | Flyway (`V1__srs_init.sql`, `V2__rls.sql`) |

### 2.2 Table DDL

```sql
-- Skills
CREATE TABLE skills (
  skill_id    VARCHAR(64) PRIMARY KEY,
  tenant_id   VARCHAR(64) NOT NULL,
  name        VARCHAR(128) NOT NULL,
  version     VARCHAR(32)  NOT NULL,         -- SemVer
  type        VARCHAR(32)  NOT NULL,
  schema      JSONB        NOT NULL,          -- parameters/returns/rate_limit/permissions
  deps        JSONB,                          -- [{skill, versionRange}]
  enabled     BOOLEAN NOT NULL DEFAULT FALSE,
  package_ref VARCHAR(256),                   -- object store reference (optional)
  UNIQUE (tenant_id, name, version)
);

-- Rules
CREATE TABLE rules (
  rule_id   VARCHAR(64) PRIMARY KEY,
  tenant_id VARCHAR(64) NOT NULL,
  name      VARCHAR(128) NOT NULL,
  version   VARCHAR(32) NOT NULL,
  engine    VARCHAR(16)  NOT NULL,           -- opa / drools
  policy    TEXT         NOT NULL,
  action    VARCHAR(8)   NOT NULL,           -- block / warn / log
  enabled   BOOLEAN NOT NULL DEFAULT TRUE,
  UNIQUE (tenant_id, name, version)
);

-- Specs
CREATE TABLE specs (
  spec_id       VARCHAR(64) PRIMARY KEY,
  tenant_id     VARCHAR(64) NOT NULL,
  name          VARCHAR(128) NOT NULL,
  kind          VARCHAR(16) NOT NULL,         -- input / output
  input_schema  JSONB,
  output_schema JSONB,
  examples      JSONB,
  UNIQUE (tenant_id, name, kind)
);

-- Skill Tests
CREATE TABLE skill_tests (
  test_id   VARCHAR(64) PRIMARY KEY,
  skill_id  VARCHAR(64) NOT NULL REFERENCES skills(skill_id),
  status    VARCHAR(16) NOT NULL,
  report    JSONB
);
```

### 2.3 JPA Entity Mapping

| Entity | Table | JSONB Columns |
| --- | --- | --- |
| `SkillEntity` | `skills` | `schema`, `deps` (via `@Convert`) |
| `RuleEntity` | `rules` | — |
| `SpecEntity` | `specs` | `input_schema`, `output_schema`, `examples` (via `@Convert`) |
| `SkillTestEntity` | `skill_tests` | `report` (via `@Convert`) |

### 2.4 Value Object Column Types

| Domain VO | DB Column | Type |
| --- | --- | --- |
| `SemVer` | `skills.version`, `rules.version` | `VARCHAR(32)` |
| `SkillType` | `skills.type` | `VARCHAR(32)`, enum: mcp_tool/http_tool/... |
| `EngineType` | `rules.engine` | `VARCHAR(16)`, enum: opa/drools |
| `RuleAction` | `rules.action` | `VARCHAR(8)`, enum: block/warn/log |
| `SpecKind` | `specs.kind` | `VARCHAR(16)`, enum: input/output |
| `ToolSchema` | `skills.schema` | `JSONB` |

## 3. Configuration

### 3.1 Service Configuration

```yaml
openstrata:
  service:
    port: 8083
  features:
    srs:
      enabled: false              # starter=false; standard/advanced/full=true
    skillTest:
      enabled: true               # Promptfoo automated testing
    ruleEngine:
      opa:
        enabled: true             # default engine
      drools:
        enabled: false            # alternative (behavior/approval rules)
  spi:
    auth:   { provider: keycloak }
    cache:  { provider: redis }   # valkey alternative
    objectStore:
      enabled: false              # enable for large file packages (MinIO)
```

### 3.2 Profile → Feature Matrix

| Profile | srs.enabled | skillTest | ruleEngine.opa | ruleEngine.drools | objectStore |
| --- | --- | --- | --- | --- | --- |
| starter | false | — | — | — | — |
| standard | true | true | true | false | false |
| advanced | true | true | true | false | optional |
| full | true | true | true | true | optional |

### 3.3 Configuration Keys Reference

| Key | Type | Default | Profiles | Description |
| --- | --- | --- | --- | --- |
| `openstrata.service.port` | int | `8083` | all | HTTP listen port |
| `openstrata.features.srs.enabled` | bool | `false` | all | Enable SRS service |
| `openstrata.features.skillTest.enabled` | bool | `true` | standard+ | Enable Promptfoo testing |
| `openstrata.features.ruleEngine.opa.enabled` | bool | `true` | standard+ | Enable OPA/Rego engine |
| `openstrata.features.ruleEngine.drools.enabled` | bool | `false` | full | Enable Drools engine |
| `openstrata.spi.auth.provider` | string | `keycloak` | all | Auth SPI provider |
| `openstrata.spi.cache.provider` | string | `redis` | all | Cache SPI provider |
| `openstrata.spi.objectStore.enabled` | bool | `false` | optional | Enable MinIO object store |
